Synchronous vs Asynchronous:
-----------------------------
If you have multiple task it will complete all the tasks in sequential manner.(1,2,3,4..

if you have multiple tasks the excecution completes in parallel manner.(1,4,2,3,6,..)

whenever you are using Asynchronous you have to use await keyword in it.
if you don't have asynchronous in it will throw an error.

In order to run the aysnchronous you have to install below command.

pip install pytest-asyncio

2 ) pytest -v -s file_name.py --headed --browser firefox --browswer chromium.

Locators:
------------

1) Identifying/ locating the web elements.
2) Perfroming actions
3) Validations

Locating the elements:
----------------------
1. everything that present in the web page is a element.
ex: add to cart, purchase, export, login buttons,
These can be done by using identifying/ locating using elements.

different types of finding locators:
-------------------------------------
1) playwright built-in locators.(1st prior complex elements can't find(ex: iframes, nested frames).
2) xpath
3) CSS (so we use CSS as 1st priority).

Below are some playwright built in locators:
---------------------------------------------
page.getByRole() to locate by explicit and implicit accessibility attributes.
page.getByText() to locate by text content.
page.getByLabel() to locate a form control by associated label's text.
page.getByPlaceholder() to locate an input by placeholder.
page.getByAltText() to locate an element, usually image, by its text alternative.
page.getByTitle() to locate an element by its title attribute.
page.getByTestId() to locate an element based on its data-testid attribute (other attributes can be configured).
